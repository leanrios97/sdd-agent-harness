# SDD Agent Harness

Harness reutilizable e independiente de la herramienta para desarrollo guiado por especificaciones (SDD) asistido por IA. Coordina agentes de programación (Claude Code, Codex CLI, Gemini CLI, GitHub Copilot) mediante un contrato compartido, un pipeline de especificaciones con controles de calidad y puntos de revisión humana.
